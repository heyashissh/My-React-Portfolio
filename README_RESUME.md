# Ashish Shrivastav Portfolio — Resume Update

This version includes a responsive Resume section.

- **View Resume** opens `public/Ashish_Shrivastav_Final_Resume.pdf` in a new browser tab.
- **Download PDF** downloads the same resume.
- Resume is included in the project, so it works after deployment to Vercel, Netlify, GitHub Pages (with the appropriate base path), or another static host.

Run:

```bash
npm install
npm run dev
```
